# 场景背景

## 店铺信息

- 店铺名称：好居家旗舰店
- 主营类目：家居收纳、厨房用品、浴室配件
- 平台：淘宝/天猫
- 月均 GMV：约 18 万元
- 广告占比：约 12%

## 当前问题

近两周广告花费持续走高，但转化效率下降。运营负责人发现部分关键词点击异常偏高（疑似竞品恶意点击或爬虫），同时部分低 ROI 词占用了过多预算份额。

## 任务目标

通过系统性的关键词诊断、出价优化和预算再分配，在日预算 600 元约束下实现最优投放效率。

## 数据说明

- 所有数据为近 7 天（2026-05-14 至 2026-05-20）的累计值
- 收入为该关键词带来的直接成交 GMV（不含间接转化）
- 点击费用 = 实际扣费（CPC × 点击数的近似值）
