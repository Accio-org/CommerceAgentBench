# 泰国站 11.11 大促 — 运营 Brief

## 背景

公司在泰国市场运营 3C 配件品类，同时在 Shopee Thailand、Lazada Thailand 和 TikTok Shop Thailand 三个平台销售。双十一大促是年度最重要的促销节点，需要统一规划定价和库存分配。

## 仓储架构

- **深圳中心仓 (cn_warehouse)**：存放全品类现货，通过跨境物流发往泰国。成本优势在低价轻量商品（国际运费按重量阶梯计费）。
- **曼谷保税仓 (th_warehouse)**：已预先进口的本地库存，需承担关税 + VAT + 仓储附加费，但时效快（1-3 天达），转化率高。

## 核心诉求

1. **统一报价矩阵**：每个 SKU × 平台组合给出常规价、三种促销价（Flash Sale / Platform Voucher / Normal Promo），并标注最优促销层级。
2. **库存分配**：根据销售速率和促销期（7 天）计算各平台所需库存，从最优仓库优先分配，受仓库可用量上限约束。
3. **促销合规**：确保所有促销价格不低于地板价（≥5% 毛利），不超过竞品天花板价。
4. **预算控制**：总促销库存成本不超过 800,000 THB。

## 决策偏好

- Flash Sale 优先给 TikTok（流量增长最快），其次 Shopee，最后 Lazada。
- 如果 Flash Sale 不满足地板价，降级到 Platform Voucher；再不满足降到 Normal Promo。
- 每个平台最多 4 个 Flash Sale 名额。
- 优先保证高销售速率的 SKU 有充足库存。

## 时间节点

- 促销期：2026-11-11 至 2026-11-17（7 天）
- 报价提交截止：2026-11-01
- 库存锁定截止：2026-11-05
