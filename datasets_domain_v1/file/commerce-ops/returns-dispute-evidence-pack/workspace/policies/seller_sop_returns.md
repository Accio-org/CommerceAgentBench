# Seller SOP - Return Review

- Use neutral language in all buyer-facing messages.
- For two-pack returns, compare outbound packed weight, carrier acceptance weight, return weight, and receiving photos.
- If one unit is returned from a two-pack, offer partial refund unless marketplace policy requires full refund or evidence is inconclusive.
- If damage appears carrier-caused, preserve the buyer experience and file a carrier claim separately.
- Never use language such as fraud, scam, bad faith, or accusation in customer-safe responses.
