## Product Description Highlights (English description reference)

Core selling points to cover when writing the description:
1. Material advantage: 100% TPE eco-friendly material, no PVC, no latex, no heavy metals, SGS certified
2. Non-slip performance: dual-sided texture design, wet & dry non-slip, suitable for all yoga styles (hot yoga, flow yoga)
3. Comfortable thickness: 6mm thickness, balancing joint protection and stability
4. Lightweight portability: includes carrying strap and tote bag; unrolled size 183cm x 61cm; weight only 1.2kg
5. Customization service: supports custom logo print and custom colors, suitable for yoga studios and brand customization
6. Easy cleaning: closed-cell surface structure, sweat-resistant and antibacterial, just wipe with damp cloth
