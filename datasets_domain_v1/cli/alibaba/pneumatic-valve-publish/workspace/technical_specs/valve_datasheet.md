# Technical Datasheet — ZD-PBV-DN50 Pneumatic Ball Valve

## General Description
Pneumatic actuated stainless steel ball valve for industrial flow control applications. The ZD-PBV-DN50 features a double-acting pneumatic actuator with 304 stainless steel body and PTFE seals, suitable for water treatment, chemical processing, and general industrial piping.

## Technical Specifications

| Parameter | Value |
|-----------|-------|
| Model | ZD-PBV-DN50 |
| Type | Two-piece ball valve with pneumatic actuator |
| Nominal Size | DN50 (2") |
| Connection | Flanged, ANSI 150 / PN16 |
| Body Material | ASTM A351 CF8 (SS304) |
| Ball Material | SS304, precision polished |
| Seat Material | PTFE (Teflon) |
| Stem Material | SS304 |
| Actuator | Double-acting pneumatic, rack & pinion |
| Actuator Model | AT-065D |
| Air Supply | 4-7 bar (58-102 psi) |
| Operating Torque | 22 N·m |
| Working Pressure | PN16 (16 bar / 232 psi) |
| Temperature Range | -20°C to +180°C |
| Port Type | Full bore |
| Leakage Rate | Zero leakage (Class VI) |
| Cycle Life | >100,000 cycles |
