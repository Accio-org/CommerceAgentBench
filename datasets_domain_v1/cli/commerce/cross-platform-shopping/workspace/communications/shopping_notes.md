## 平台比较总结

|  | 鲸东(JD) | 天猫(TM) | 拼夕夕(PDD) |
|--|---------|---------|------------|
| 速度 | 最快(1天) | 中(2天) | 慢(4天) |
| 价格 | 偏高 | 中等 | 最低 |
| 包邮 | 满99 | 满88 | 满49 |
| 券 | 满199-20 | 满149-15 | 满79-10 |

## 注意事项

1. 急需商品 → 只能JD或TM（PDD太慢！）
2. 插排 → TM缺货，只能从JD买
3. 晾衣架 → PDD没有好的/缺货，只看JD和TM
4. 优化目标 = 商品总价 + 运费 - 优惠券，越低越好
5. 要凑单触发优惠券！哪怕单品贵几块，凑到门槛能省更多
