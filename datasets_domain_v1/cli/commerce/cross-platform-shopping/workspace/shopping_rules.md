# 多平台凑单购物规则说明

> 搬新家采购场景。你需要在3个平台之间分配12件商品，使总花费最低。

---

|------|---------|---------------|---------|--------|
| 鲸东商城(JD) | ¥99 | ¥8 | 1天 | 满199减20 |

## 核心规则

### R1 单平台购买
每件商品只能从**一个**平台购买。不能同一件商品从多个平台各买一部分。

### R2 包邮门槛
- 在某平台购买的商品总金额 ≥ 该平台包邮门槛 → 免运费
- 低于门槛 → 需支付该平台固定运费
- 如果某平台没有分配任何商品 → 不产生运费

### R3 平台优惠券
- 每个平台提供一张满减优惠券
- 条件: 该平台商品总金额 ≥ 优惠券门槛
- 每平台最多抵扣一次
- 优惠券门槛按商品原价计算，不含运费

### R4 紧急商品约束
- 标记 `urgent=true` 的商品**必须2天内送达**
- 鲸东商城(JD): 1天送达 ✓
- 天猫优选(TM): 2天送达 ✓
- 拼夕夕(PDD): 4天送达 ✗ **不可用于紧急商品**

### R5 商品可用性
- 部分商品在某些平台**缺货**（标记为 available=false 或 price=null）
- 缺货商品不可从该平台购买

### R6 优化目标
**最小化总花费**:
```
总花费 = 各平台商品价格之和 + 各平台运费之和 - 各平台优惠券抵扣之和
```

### R7 优惠券门槛判定
- 优惠券是否可用取决于**该平台的商品原价总额**
- 运费不计入门槛
- 先判定是否达标，再扣除优惠

## 凑单策略提示

直觉上把所有东西放最便宜的平台看起来省钱，但要注意：
1. **包邮门槛**: 金额太低可能要付运费，抵消了价格优势
2. **优惠券触发**: 差一点达到优惠券门槛时，把某件稍贵的商品移过来可能总体更省
3. **平台间联动**: 从A平台移走一件商品可能让A失去优惠券资格，需要全局考虑

这是一个需要综合考虑多个因素的优化问题，不能只看单品最低价。
