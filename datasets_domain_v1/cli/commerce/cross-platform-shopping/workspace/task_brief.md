# 任务简介：多平台比价凑单方案

## 场景

你刚搬了新家，需要采购一批生活用品。你列了一个 12 件商品的购物清单，打算在 3 个电商平台（鲸东商城 / 天猫优选 / 拼夕夕）之间比价购买，制定最优的跨平台购物方案。

## 核心挑战

这不是简单的"每件选最便宜"的问题。各平台有不同的包邮门槛和优惠券，商品分配到不同平台会互相影响——从一个平台移走一件商品可能导致它失去优惠券资格，而移入另一个平台可能让它触发新的优惠。

## 目标

**最小化总花费** = 商品价格 + 运费 - 优惠券

## 工作流程

1. 调用购物 API 获取平台信息、商品清单、各平台价格、规则
2. 考虑约束（紧急商品、缺货、包邮门槛、优惠券门槛）
3. 制定最优分配方案
4. 输出到 `outputs/shopping_plan.json`
