# Weekly Feed QA Summary Policy — Week 23

## Inclusion criteria

A QA document is included in the weekly summary only if **all** of the following are true:

1. It is a **feed QA document** (contains SKU, issue code, severity fields — not meeting notes, checklists, or other non-QA documents).
2. Its **Review Cycle** is the **current cycle** (Week 23). Documents from prior cycles (archived) must be excluded.
3. Its **Severity** is **High** or **Highest**. Medium-severity issues are tracked separately and excluded from this summary.
4. Its **Status** is **Open**.

Documents in the `Archive — Prior Cycles` folder should be excluded regardless of their content.

## Summary document

Create one document named **Week 23 Feed QA Summary** under the knowledge base root folder. Structure:

```
# Week 23 Feed QA Summary

Review Cycle: Week 23
Generated by: Marketplace Ops

## Summary
Total issues reviewed: <count of all QA docs in current cycle>
Included (High/Highest): <count of included>
Excluded (Medium or archived): <count of excluded>

## Included Issues

| SKU | Market | Channel | Issue Code | Severity | Expected Action |
|-----|--------|---------|------------|----------|----------------|
| ... | ... | ... | ... | ... | ... |

## Issue Breakdown by Domain
| Domain | Count |
|--------|-------|
| ... | ... |
```

Sort included issues by severity (Highest first), then by SKU alphabetically.

## Comments on included documents

For each QA document included in the summary, add a **global comment** on that document with the text:

> Included in Week 23 QA Summary — [severity] priority, action required.

Do not add comments on excluded documents. Do not modify any existing document content.
