# Returns Comment Resolution Queue Instructions

## Summary Document

Create exactly one new Google Docs document titled:

`Returns Comment Resolution Log 2026-W22`

The document must contain these required lines:

- `# Returns Comment Resolution Log 2026-W22`
- `Resolved SG open return comments: 3`
- `Reply used: Acknowledged for Returns Comment Resolution Log 2026-W22 — CX owner will update replacement visibility before Friday close.`
- `Next step: review the resolved comment queue in Friday closeout.`

For each qualifying source document, add one line that includes:

- Case ID
- SKU
- Channel
- Reason
- Ticket count

## Inclusion Criteria

Resolve and reply to an existing comment only when all are true:

- `Market` is `SG`
- `Status` is `Open`
- `Tickets` is at least `8`

Do not resolve comments for lower-ticket open records, exchange-requested records, policy-review records, or any non-SG market.

## Required Comment Reply

Reply to each qualifying source comment with this exact text:

`Acknowledged for Returns Comment Resolution Log 2026-W22 — CX owner will update replacement visibility before Friday close.`

After replying, mark the same comment as resolved.
