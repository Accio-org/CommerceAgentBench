# Feed QA Brief — 2026-W22

## Summary Document

Create one Google Docs document titled exactly:

`Feed QA Weekly Summary 2026-W22`

Place the provided status image `feed_status_badge.svg` near the top of the document through Google Docs' image upload flow.

## Inclusion Criteria

Include a source QA document only when both are true:

- `Severity` is `High`
- `Issue Code` is one of:
  - `BAD_LANDING_PAGE`
  - `MISSING_MAIN_IMAGE`

Do not include documents with any other issue code, even if severity is high. Do not include medium or low severity documents.

## Required Summary Content

The summary must contain:

- `# Feed QA Weekly Summary 2026-W22`
- `Total qualifying issues: 4`
- `BAD_LANDING_PAGE: 2`
- `MISSING_MAIN_IMAGE: 2`
- One line for each qualifying product in this format:
  - `<SKU> — <Market> / <Channel> — <Issue Code> — <Expected Action>`
- `Next step: remediation before the next feed submission.`

## Required Source Comments

For every included source QA document, add this exact comment text:

`Included in Feed QA Weekly Summary 2026-W22 — please start remediation before the next feed submission.`

Place the comment on that source document's `Issue Code:` line.

Leave all excluded source documents without new comments.
