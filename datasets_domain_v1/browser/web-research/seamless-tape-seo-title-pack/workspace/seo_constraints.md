# Listing 标题约束

- 字符上限：128 英文字符
- 必含核心词：acne patch / pimple patch / hydrocolloid
- 黄金公式：[卖点] + [营销] + [属性/参数] + [核心词] + [for/with 长尾]
- 关键词置后；后缀用 for/with 引导
- 输出 20 个，去重
- 每个标题需标注核心词、长尾意图、字符数
- 避免高风险功效承诺：cure, guaranteed, permanent, medical treatment, doctor approved, healing, scar prevention, inflammation reduction, redness relief, therapy, skin repair/removal 等无证或医学疗效表达
- 标题里不要使用功效结果词；优先使用 cover, absorbs oil, blemish care, invisible, waterproof, thin, sensitive skin, custom shape, OEM/ODM 等可观察属性和采购属性
- Listing pack 需额外包含：英文短描述、5 个 bullet points、10 个 search terms、标题 A/B 分组建议
