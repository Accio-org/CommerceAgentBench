Usage:
  stripe charges create [--param=value] [-d "nested[param]=value"]

Examples:
  $ stripe charges create --amount <integer> --application-fee <integer> ...

[Agent guidance]
  Use --api-key to pass your key non-interactively (or set STRIPE_API_KEY).
  Use -d to set nested params, e.g. -d "metadata[key]=value".
  Run stripe --map to quickly see all available commands.
  Run stripe resources to discover all available API resources.
  Run stripe [resource] --help to see operations and required/common parameters for a resource.
  Run stripe help [resource] [operation] to see the full parameter list for a specific operation.
  Use --stripe-account to make requests on behalf of connected accounts.

Request Parameters:
      --amount <integer>
          Amount intended to be collected by this payment
      --application-fee <integer>
      --currency <currency>
          Three-letter [ISO currency
          code](https://www.iso.org/iso-4217-currency-codes.html), in lowercase
      --customer <string>
          The ID of an existing customer that will be charged in this request
      --description <string>
          An arbitrary string which you can attach to a `Charge` object
      --destination.account <string>
          ID of an existing, connected Stripe account
      --receipt-email <string>
          The email address to which this charge's
          [receipt](https://docs.stripe.com/dashboard/receipts) will be sent
      --shipping.name <string>
          Recipient name
      --source <string>
          A payment source to be charged
      --statement-descriptor <string>
          For a non-card charge, text that appears on the customer's statement
          as the statement descriptor
      --statement-descriptor-suffix <string>
          Provides information about a card charge

  ... and 18 more parameters (stripe help charges create)
