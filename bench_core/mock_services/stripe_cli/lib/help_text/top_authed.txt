The official command-line tool to interact with Stripe.

Usage:
  stripe [command]

[Agent guidance]
  Visit https://docs.stripe.com/llms.txt?utm_source=cli for latest guidance on how to integrate correctly.
  Run `npx skills add --all stripe/ai` to add all Stripe AI skills to your agent.
  Additional commands (apps, docs, generate, projects) are available as installable plugins — run the command directly to be prompted, or use `stripe plugin install <name>`.
  Use --api-key to pass your key non-interactively (or set STRIPE_API_KEY).
  Run stripe --map to quickly see all available commands.
  Run stripe resources to discover all available API resources.
  Run stripe [resource] --help to see operations and required/common parameters for a resource.
  Run stripe help [resource] [operation] to see the full parameter list for a specific operation.


Webhook commands:
  listen                                   Listen for webhook events
  trigger                                  Trigger test webhook events

Stripe commands:
  logs                                     Interact with Stripe API request logs

Resource commands:
  charges                       Make requests (capture, create, list, etc) on charges
  customers                     Make requests (create, delete, list, etc) on customers
  payment_intents               Make requests (cancel, capture, confirm, etc) on payment intents
  ...                           To see more resource commands, run `stripe resources help`
  v2                            To see only v2 resource commands, run `stripe v2 help`

API commands:
  get                           Make GET requests to the Stripe API
  post                          Make POST requests to the Stripe API
  delete                        Make DELETE requests to the Stripe API

Other commands:
  apps                                     This plugin lets you build and manage Stripe Apps.
  community                                Chat with Stripe engineers and other developers
  completion                               Generate bash, zsh, and fish completion scripts
  config                                   Manually change the config values for the CLI
  docs                                     Browse Stripe documentation and API reference.
  feedback                                 Provide us with feedback on the CLI
  fixtures                                 Run fixtures to populate your account with data
  generate                                 This plugin creates skeleton files to get you started.
  help                                     Help about any command
  login                                    Login to your Stripe account
  logout                                   Logout of your Stripe account
  open                                     Quickly open Stripe pages
  projects                                 This plugin scaffolds and manages Stripe integration projects.
  samples                                  Sample integrations built by Stripe
  serve                                    Serve static files locally
  tools                                    Search, inspect, and execute Stripe operations not available in the public API.
  version                                  Get the version of the Stripe CLI
  whoami                                   Show the current Stripe auth state

Flags:
      --api-key string        Your API key to use for the command
      --color string          turn on/off color output (on, off, auto)
      --config string         config file (default is
                              $HOME/.config/stripe/config.toml)
      --device-name string    device name
  -h, --help                  help for stripe
      --log-level string      log level (debug, info, trace, warn, error)
                              (default "info")
      --map string[="tree"]   Print a command tree [tree|compact|paths|json]
  -p, --project-name string   the project name to read from for config
                              (default "default")
  -v, --version               Get the version of the Stripe CLI

Use "stripe [command] --help" for more information about a command.
