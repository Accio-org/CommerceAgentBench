Usage:
  stripe refunds create [--param=value] [-d "nested[param]=value"]

Examples:
  $ stripe refunds create --amount <integer> --charge <string> ...

[Agent guidance]
  Use --api-key to pass your key non-interactively (or set STRIPE_API_KEY).
  Use -d to set nested params, e.g. -d "metadata[key]=value".
  Run stripe --map to quickly see all available commands.
  Run stripe resources to discover all available API resources.
  Run stripe [resource] --help to see operations and required/common parameters for a resource.
  Run stripe help [resource] [operation] to see the full parameter list for a specific operation.
  Use --stripe-account to make requests on behalf of connected accounts.

Request Parameters:
      --amount <integer>
      --charge <string>
          The identifier of the charge to refund
      --currency <currency>
          Three-letter [ISO currency
          code](https://www.iso.org/iso-4217-currency-codes.html), in lowercase
      --customer <string>
          Customer whose customer balance to refund from
      --instructions-email <string>
          For payment methods without native refund support (e.g., Konbini,
          PromptPay), use this email from the customer to receive refund
          instructions
      --origin customer_balance
          Origin of the refund
      --payment-intent <string>
          The identifier of the PaymentIntent to refund
      --reason duplicate|fraudulent|requested_by_customer
          String indicating the reason for the refund

  ... and 2 more parameters (stripe help refunds create)
