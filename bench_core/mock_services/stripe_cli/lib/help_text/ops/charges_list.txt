Usage:
  stripe charges list [--param=value] [-d "nested[param]=value"]

[Agent guidance]
  Use --api-key to pass your key non-interactively (or set STRIPE_API_KEY).
  Use -d to set nested params, e.g. -d "metadata[key]=value".
  Run stripe --map to quickly see all available commands.
  Run stripe resources to discover all available API resources.
  Run stripe [resource] --help to see operations and required/common parameters for a resource.
  Run stripe help [resource] [operation] to see the full parameter list for a specific operation.
  Use --stripe-account to make requests on behalf of connected accounts.

Request Parameters:
      --created <integer>
          Only return charges that were created during the given date interval
      --customer <string>
          Only return charges for the customer specified by this customer ID
      --ending-before <string>
          A cursor for use in pagination
      --limit <integer>
          A limit on the number of objects to be returned
      --payment-intent <string>
          Only return charges that were created by the PaymentIntent specified
          by this PaymentIntent ID
      --starting-after <string>
          A cursor for use in pagination
      --transfer-group <string>
          Only return charges for this transfer group, limited to 100

Flags:
  -c, --confirm                 Skip the warning prompt and automatically
                                confirm the command being entered
      --dark-style              Use a darker color scheme better suited
                                for lighter command-lines
  -d, --data stringArray        Data for the API request
      --dry-run                 Preview the request without sending it
  -e, --expand stringArray      Response attributes to expand inline
  -h, --help                    help for list
  -i, --idempotency string      Set the idempotency key for the request,
                                prevents replaying the same requests
                                within 24 hours
      --live                    Make a live request (default: test)
  -s, --show-headers            Show response headers
      --stripe-account string   Set a header identifying the connected account
      --stripe-context string   Set a header identifying the compartment
                                context
  -v, --stripe-version string   Set the Stripe API version to use for your
                                request

Global Flags:

      --color string          turn on/off color output (on, off, auto)
      --config string         config file (default is
